## 修订内容

- 恢复真正的 Bun 锁文件管理，冻结安装；不再忽略锁文件或使用 `--no-save` 浮动解析。
- 保留有效 PWA 文件原字节：禁用新注册，替换 Worker 只处理 install／activate，不拦截 fetch。
- 构建拒绝必需资源缺失或源／产物 PWA 字节不同；增加主题身份、版本和网络模式校验。
- 使用 Node 内置测试器，六组正／负例覆盖注册、fetch、缺文件、资源被改、版本／身份漂移及空预览／首页。
- 新构建 CI 在 Windows／Linux 验证固定依赖与打包；发行同样执行回归和构建，禁止覆盖已有附件。
- 校正贡献指南中的 CI 和测试约定，不宣称已有完整 UI 单测或覆盖率目标。

## 本机验证与边界

最初旧 `node_modules` 混有 pnpm 的 Vue 3.5.41 与 Bun 解析的 Vue 3.5.43，产生跨依赖 Ref 类型错误。干净目录冻结安装后类型检查／构建通过；旧依赖保存在忽略的 `.tools/node_modules-pre-bun-20261001`，没有为这类错误重写组件。

在当前目录重新安装一致依赖后，非改写 lint、六组回归、Vue 类型检查、Vite 和打包校验通过。远端新 CI 尚未执行；没有声称重验全部浏览器行为。既有 Worker 的自然更新仍取决于浏览器，不在本轮强刷或清理数据。

manifest／package 仍为 `2.2.2-mxh.9`；本地维护包不是新正式发行。后续公开发行应递增版本、核对对应提交及附件摘要，再单独选择生产安装。
