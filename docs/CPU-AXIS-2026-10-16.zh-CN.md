# CPU 与系统负载图表说明

## 问题与修正

CPU 使用率与系统负载是两个不同单位的指标。旧图表的 CPU 左轴已经固定为 0–100%，但系统负载右轴完全随数据缩放：单核机器的负载峰值只有 0.39 时也会接近图顶。横向游标还显示鼠标位置对应的轴值，容易把橙色负载峰值误读为接近 100% 的 CPU 使用率。

本次保留原始监控数据，调整展示：

- 卡片标题改为「CPU 与负载」，增加左右轴图例和单位说明；轴颜色与曲线对应。
- CPU 左轴继续固定为 0–100%，18.5% 的点位于 20% 刻度下方。
- 系统负载右轴从零开始，最大值至少为节点报告的逻辑核心数；未知或无效核心数按 1 作为展示基线。峰值超出基线时，按峰值乘 1.1 后向上取整扩展，避免截断。
- 悬浮提示分别注明「CPU 使用率（左轴）」和「系统负载（右轴）」；仅保留时间方向的游标，不再展示横向鼠标坐标数值。
- 悬浮框限制在图表区域内，窄屏也能完整读取指标名称和数值。
- 缺测仍为空缺，提示为「—」；负载不添加百分号，不做 CPU 百分比换算。

逻辑核心数只是负载刻度的容量参考，不是主控提供的性能评分，也不代表负载始终不能超过该值。

## 验证

使用真实 `LoadChart` 组件和本地合成数据验证以下场景，未改动生产监控记录：

- CPU 18.5%、负载 0.39，单核负载轴最大值为 1。
- 四核容量基线与高负载峰值自动扩展。
- 全零、负载缺测、实时和 15 天历史视图。
- 深色与浅色显示、悬浮数值和游标方向；浏览器无警告或错误日志。

同时执行 lint、类型检查、完整构建及现有打包契约检查。浏览器场景使用合成数据，不等同于对所有生产历史数据的逐点验收。
